# Verification Gates

Match evidence to the changed boundary: focused test for logic; typecheck for interfaces; production build for build configuration; real artifact inspection for packaging; process readiness and logs for IPC/runtime; rendered interaction and accessibility state for UI; installed launch for installers.

Do not substitute source grep for behavior, a successful build for a launch, or an unpacked directory for an installer. Preserve baseline failures separately and do not expand scope unless they block the requested outcome.
