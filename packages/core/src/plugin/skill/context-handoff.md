# Context Handoff

For long or interrupted work, maintain a compact durable state with the objective, scope, repository/branch/commit, worktree state, confirmed facts, decisions, rejected false leads, exact files and commits, check results, artifact paths/hashes, safety constraints, open risks, and one exact next action.

Update after root cause, commit, test phase, build, package, runtime acceptance, or before context loss. Put the current summary first so historical OPEN or FAIL entries are not mistaken for present state.
