# Ponytail

Understand the real flow, then choose the first complete solution that holds: skip speculation, reuse existing code, use the standard library, use a native platform feature, use an installed dependency, then write the minimum new code.

Fix root causes at shared boundaries. Avoid one-use factories, single-implementation interfaces, pass-through wrappers, premature configuration, and dependencies that replace a few clear lines.

Never simplify away validation, security, accessibility, recoverability, error handling, or requested behavior. Leave the smallest runnable regression check for non-trivial logic.
