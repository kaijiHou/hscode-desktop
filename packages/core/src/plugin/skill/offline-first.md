# Offline-First Work

Inventory local executables, caches, vendored archives, lockfiles, mirrors, snapshots, and prior artifacts before using the network. Prefer exact cached versions, verify hashes, and record actual paths.

Avoid automatic installers and network-backed commands. Do not change declared versions merely to match installed tools. For another machine, bundle source history, lockfiles, required runtimes, native assets, licenses, hashes, and a plain-text restore manifest.
