# HSCode 使用手册

## 1. HSCode 是什么

HSCode 是一款基于 OpenCode 的本地 AI 编程助手桌面应用。它提供：

- 与 AI 模型对话（OpenCode Go、DeepSeek、自部署模型）
- 本地终端
- 网络抓包分析
- 多服务器支持（本地 + 远程）
- 文件编辑、代码搜索等工具调用能力

## 2. 主界面介绍

- **左侧**：对话区域，与 AI 交互
- **右侧/底部**：工具面板（终端、网络抓包）
- **顶栏**：项目名、模型选择、设置入口
- **底部工具栏**：终端 / 网络抓包 切换按钮

## 3. 项目

### 打开项目

启动 HSCode 后，选择或创建一个项目目录。HSCode 会在该目录下工作。

### Default Project

如果未指定项目，HSCode 会使用默认项目。你可以在设置中切换。

### 新建会话

在项目中点击"新建会话"，即可开始与 AI 对话。

### 会话标签

支持多个会话标签，可在顶部切换不同对话。

## 4. 对话与 Agent

### 输入问题

在底部输入框输入问题，按发送按钮或 Enter 键发送。

### 文件上下文

AI 可以读取项目中的文件。使用 `@文件名` 引用特定文件。

### 命令

输入 `/` 开头的命令，如：
- `/help` — 显示帮助
- `/clear` — 清除上下文

### Shell/Tool Calls

AI 可以执行终端命令、编辑文件、搜索代码等。需要授权时会弹出确认。

### 权限

某些操作（如文件写入、命令执行）需要用户授权。HSCode 会提示你确认。

## 5. 模型

### OpenCode Go

OpenCode 官方模型服务，提供低成本订阅。

### DeepSeek

DeepSeek 官方 API。需要 API Key。

### 自定义 OpenAI-Compatible

连接自己部署的模型服务（如 llama.cpp、vLLM、Ollama 等）。

**配置方法**：
1. 点击"选择模型" → "自定义模型"
2. 填写 Provider Name、Base URL
3. API Key（可留空）
4. Model ID
5. 点击"保存"

## 6. 终端

### 打开/关闭

点击底部工具栏的"终端"按钮，或使用快捷键。

### 新终端

支持多个终端标签，可并行运行。

### 终端 Tab

在终端面板顶部切换不同终端会话。

## 7. 网络抓包

详见 [网络抓包使用手册](network-capture-guide.md)。

## 8. 服务器

### 本地服务器

HSCode 内置本地后端服务，负责项目管理、会话、模型调用等。在设置 → 服务器中可查看详情。

### 添加远程服务器

在设置 → 服务器中点击"添加服务器"，填写远程服务器地址。

## 9. 设置

点击右上角齿轮图标进入设置：
- **通用**：语言、主题
- **模型**：模型提供商配置
- **服务器**：本地/远程服务器管理
- **快捷键**：键盘快捷键配置

## 10. 常见错误

| 错误 | 原因 | 解决 |
|---|---|---|
| "模型服务加载失败" | 网络或配置问题 | 检查 API Key 和网络 |
| "抓包需要管理员权限" | WinDivert 需要管理员 | 以管理员身份运行 |
| "HSCode 加载失败" | 侧边栏服务异常 | 重启应用 |

## 11. 隐私说明

- HSCode 普通启动不主动访问外部服务
- 模型 API 调用仅在用户主动选择模型后发生
- 本地数据存储在项目目录下
- 网络抓包数据仅在本地处理

## 12. 当前已知限制

- 不支持 TLS/HTTPS 内容解密
- 不支持 TCP 流重组
- 不支持 HTTP/2 完整解析
- 不支持 QUIC 解密
- 网络抓包需要管理员权限（Windows）
